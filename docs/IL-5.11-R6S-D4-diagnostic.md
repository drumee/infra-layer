Reprise de `6f5c3ef`, arbre propre ; main distant inchangé `a02b76e4c421e96e63406d7b10edc2b76a6056c1`. L’arrêt initial et ses preuves restent dans evidence/IL-5.11-R6S. Aucun helper modifié avant ce diagnostic.

**Cause reproduite : erreur de traversée du parent privé dans le harnais D4.** Le conteneur est créé et Node démarre ; `chown('/fixture/foreign',65532,65532)` renvoie **EACCES**, exit1. Le bind monte la racine de fixture UID1000/GID1000, mode0700. Le processus conteneur UID0/GID0 ne possède que CAP_CHOWN (CapEff=1), sans CAP_DAC_OVERRIDE ni CAP_DAC_READ_SEARCH : il ne peut pas traverser ce parent pour atteindre l’enfant. La sonde séparée confirme `stat('/fixture/foreign') → EACCES` avant tout changement d’ownership. Ce n’est ni un refus de création/montage ni une vérification réussie de l’ownership par le helper.
