# Error contract decision

Gate B PASS. A well-formed role string absent from compose.networks contradicts the declared membership relationship and must return NETWORK_ATTACHMENT_MISMATCH. This preserves historical consumer semantics independently of test green status. Empty, duplicate, non-string or syntactically invalid roles and malformed endpoint metadata remain INVALID_NETWORK_ATTACHMENT. Extra/missing/wrong-ID memberships use F1's existing NETWORK_ATTACHMENT_MISMATCH, never readiness. Ownership and Docker failures remain distinct. No existing assertion is changed.

Precedence is staged: inspect required declared networks in sorted role order, validate network schema/ownership and attachment metadata in sorted key order; then union referenced/project-inventory container IDs in sorted order; inspect each container (Docker failure remains fatal), check ownership, identity/schema, declaration structure then declaration consistency, complete membership and cross-check endpoint identities. All ordinary members precede final unsettled refusal. A malformed reverse attachment is therefore rejected before a later container mismatch. Ownership precedes container membership errors. Sorting makes those choices independent of insertion order, rather than claiming every possible mismatch outranks malformed input. No readiness bypass or broad catch is introduced.
