# D1 diagnostic design — Gate D

The original output cannot establish a first cause. Add only a new isolated diagnostic directory; preserve all original comparator, registration, expected values, negative assertions and input hashes. No corrective implementation.

Node CLI retains --test, its explicit target and default process isolation. --require loads preload.cjs in parent and worker, with --trace-uncaught. Native supported multiple reporters produce TAP plus a bounded JSON event stream. preload journals process startup/exit, target _compile start/completion/error, uncaughtExceptionMonitor and passive observation of process.emit('unhandledRejection'). Both wrappers delegate exact original arguments/return and rethrow the same load Error. No rejection/uncaughtException handler is installed to suppress fatal behavior. Module compile completion plus native enqueue/dequeue/complete events establish reachable phases without wrapping or relocating test registration.

capture.cjs records pid/ppid and bounded name/code/message/stack/cause chains; no assertion actual/expected objects or environment dump. Reporter records native test events and errors; it rethrows collection errors. Python keeps separate stdout/stderr, EOF/byte counts/full-stream hashes, capped private raw captures and redacted public text. Process journals cap131072 bytes plus one bound marker; strings8192;512 reporter events; copied side files1MiB; streams262144 bytes each. A45-second guard terminates a hung diagnostic and records timed_out; it is not a sleep or retry. Any truncation/collection gap remains explicit and cannot support missing causal evidence. Synthetic secret fields are redacted from public outputs. Raw private buffers are not published.

E1–E10 use non-Docker deterministic fixtures: success covers load+normal completion; explicit load exception/cause; explicit exception during marked registration; native assertion; unhandled rejection after setImmediate; worker exit7; injected reporter failure; assertion before later reporter error; oversized console output/redaction. Native expected nonzero exits validate fatal propagation; they are not failed preflight controls if all expected evidence is present. Any unexpected control failure creates PREFLIGHT-STOP and prohibits comparator attempt.

Exactly one later comparator attempt requires preflight PASS and an exclusive diagnostic-start marker. Added D1 env variables only identify capture directory/target; inherited NODE_OPTIONS/NODE_TEST_CONTEXT are not cleared or altered. No source or assertion fix, no selection filter, retry, permission relaxation or Docker action. A passing diagnostic leaves historical cause undetermined; an opaque attempt ends investigation. Review before qualification and final conclusions remains independent.

[Versioned Node reporter documentation](https://nodejs.org/download/release/v22.22.0/docs/api/test.html#custom-reporters) establishes the native reporter interface; actual support is also verified in installed Node CLI/source. Error propagation, registration preservation and phase fidelity must be demonstrated by preflight, not assumed from design.

Independent static observations were addressed before any diagnostic fixture execution: original exception identity survives capture failure with separately visible fatal collection failure; every individually shortened string is marked; timeouts address only the newly created owned process group and bound remaining stream drain; diagnostic source hashes are frozen alongside comparator inputs. Missing/bounded capture cannot support an unobserved causal assertion.
